A REUSABLE PUBLICATION PLATFORM

Adding a comparison

Every investigation uses the same templates and a generated comparison manifest. The platform is not limited to one character pair or encounter.

  1. Define identitiesChoose two or more characters with stable Lodestone IDs, current worlds and regions. Document any independently verified historical aliases.
  2. Choose encounter and periodValidate current/historical encounter IDs, an IANA timezone, inclusive start, exclusive end and common timeline start.
  3. Discover evidenceThe maintainer runs the private configuration-driven collection tools, prioritizing known activity windows and related uploaders without assuming complete indexes.
  4. Review participationResolve report actors, inspect same-fight participants, separate candidates and recollections, and record inaccessible periods.
  5. Prepare a public editionGenerate the reusable page and manifest. Publish only sanitized target evidence and aggregate coverage, never raw responses or credentials.
  6. Validate and publishCheck desktop/mobile rendering, filtering, evidence links, timezone correctness and limitations before approving the static release.

No fake live search

The homepage filters already-published comparisons. It does not authenticate to FFLogs or launch new investigations. A new comparison requires maintainer review; development source and collection access are private.

A stable, unique URL-safe slug identifies each report. New pages appear automatically through the manifest, without custom homepage code or a separate application.
